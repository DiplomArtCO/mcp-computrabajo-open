# Conversational skills

These skills are reusable guidance for an MCP-compatible conversational client.
They are intentionally tool-agnostic: users describe their goal in natural
language and the client maps it to the available Computrabajo tools.

- `descubrimiento.md`: buscar y preseleccionar ofertas.
- `evaluacion.md`: revisar una oferta completa y compararla con el perfil.
- `perfil.md`: consultar el perfil autenticado y los CV adjuntos.
- `postulacion.md`: preguntar, revisar, confirmar y enviar una postulación.
- `sesion.md`: diagnosticar autenticación sin exponer secretos.

The server's MCP instructions contain the same safety rules at runtime.
