# Evaluación

Para una oferta seleccionada llama a `detalle-de-oferta` con el `offerId`
devuelto por `buscar-ofertas`; nunca uses la URL como identificador. Explica
responsabilidades, requisitos, experiencia, educación, ubicación, contrato,
salario, beneficios y datos faltantes.

Si se pregunta si encaja con el perfil, llama primero a `ver-mi-perfil` y
distingue evidencia de inferencia.
